Brand and component system Handoff · v1 · Oct 2026

Three rules

01 Amber means progress The current beat, completed steps, and the “It” in the logo. Nothing decorative is amber.
02 Serif for headers and chords Fraunces for the wordmark, titles, and chord names in the grid. System sans for everything else.
03 Paper on dark A warm paper card sitting on YouTube’s dark UI. Never dark-on-dark; red belongs to YouTube.

The mark

Fraunces Bold Italic “t” over an amber swipe rotated −6°, on a paper tile.
Use for Extension icon · favicon · toolbar · popup header · loading
Geometry (112-unit tile) Radius 22 · 3px inner border #dcd7cd · swipe 92×36, r6, top 40

Lockup and wordmark

Stacked lockup Store listing, onboarding, splash. Never below 64px.
Inline wordmark Component headers and popups. The swipe sits behind “It” in every state.

Do and don’t

Do Slant only the logo swipe (−6°) Keep grid cells flat and square Use the mark alone at 32px and below Bold sans for data values
Don’t Use amber for decoration or hovers Set key, tempo or scale in serif Use the stacked lockup below 64px Use red in tabIt UI
