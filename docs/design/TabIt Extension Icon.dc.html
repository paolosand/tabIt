3a · glyph
ForSurvives 16px. The toolbar and favicon are where people see an extension most, and this is the only one that stays crisp there.One letter, one gesture. Easy to reuse as a favicon, loading mark, watermark, or merch.The amber swipe is the app’s “current chord” highlight. Icon and UI share one idea.
AgainstA lone “t” is generic. It depends on the italic serif and amber to be recognisable.It doesn’t say the name, so it needs the wordmark beside it until people know it.
3b · stacked
ForSays the whole name. More character and easier to own on day one.Highlighting “it” tells the product story: this is the chord to play now.Great at 128px and above: store tile, splash screen, social.
AgainstAt 16px it turns to mush, right where it’s seen most often.Two lines of type in a square is a wordmark, not an icon. Chrome’s icon guidance favours simple, text-free marks.Harder to adapt: a favicon or loading state would need a different mark anyway.
Recommendation: don’t pick one. Make them a pair. Use 3a as the mark for the extension icon, favicon, toolbar, popup header, and loading states. Use 3b as the lockup for the store tile, onboarding, splash, and social. Both rest on one device, the tilted amber swipe, and the app already uses it for the current chord. That gives the brand one rule: amber swipe = now.
